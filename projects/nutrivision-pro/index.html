Overview

NutriVision Pro is a food-scanning app: upload a photo, and a fine-tuned YOLO11-Seg model segments each food item on the plate, estimates portion size, and returns a per-item nutrition card the user can adjust with a gram slider before logging. Logged meals roll up into a daily diary tracking 16 nutrients against a personalized target derived from the user's profile.

Trained on
0

food classes — including home-cooking staples like sambal, tempeh, tofu and squid, not just generic Western food datasets.

From photo to diary

What happens after you tap Scan

Segment each item → reconcile ambiguous classes → resolve nutrition per class → correct portion with a gram slider → log to the daily diary.

Fully deployed

A real product, not a demo

FastAPI backend on AWS EC2 with the model pulled from S3 at startup, a Next.js frontend on Vercel, Firebase for auth, and Redis for caching — serving real inference traffic.
